# Рішення (DECISIONS)

- Класичні скрипти з простором `window.App` замість ES-модулів: так `site/index.html` працює при відкритті подвійним кліком із `file://` (Chrome блокує зовнішні ES-модулі на `file://`), а на Render різниці немає.
- Маршрутизація через hash (`#/`, `#/g/<id>`), щоб статичний хостинг не потребував налаштування rewrite-правил.
- Генератор підключається одним рядком у `site/js/core/registry.js` (`file`) і файлом у `site/js/generators/`; скрипт вантажиться на вимогу.
- Порожній лист A4 у фазі 1: шапка + лінія для імені + порожнє тіло; заглушка-пояснення показується лише на екрані.
- M4 у режимі «у стовпчик» малюється як ділення «куточком»; у рядок — приклад із місцем для остачі.
- L1: 12 рядків прописів на сторінку, кегль зразка авто 9–16 pt за довжиною найдовшого рядка.
- Набори слів зберігаються у site/data/wordsets.js (а не .json): etch() локального JSON блокується на ile://, а класичний скрипт працює офлайн.
- Пунктирні літери — SVG <text> зі stroke-dasharray; рукописний шрифт Caveat (OFL) покладено в site/fonts/. Порожні рядки прописів мають косу сітку 65°.
- L3: підказка-картинка поки не реалізована (необов'язковий пункт), слова лише текстом.
- L8 використовує вбудовану таблицю emoji (UA/EN) як картинки; для невідомих слів — набір запасних emoji, повторення іконок у межах завдання уникається.
- L9 і L10 не мають аркуша відповідей (`supportsAnswers: false`); L4–L6 також без відповідей, бо це прописи.
- L7 складає кросворд автоматично: перетин ≥1 літери, заборона дотику паралельних слів, добір найкращого з 24 спроб; якщо сітка замала — показує помилку біля поля.
- M5 у режимі «будиночок» показує всі розклади числа (0…N), у режимі «пропущене число» — випадкові пари в межах обраної кількості.
- M11 будує судоку backtracking-ом і перевіряє єдиність розв'язку; цільова кількість підказок 4×4: 8/6/4, 6×6: 18/14/10, 9×9: 40/32/26 (може лишитися більше, якщо прибрати клітинку неможливо).
- «Мої шаблони»: масив у localStorage під ключем `templates` (через `App.storage`), поля `id`, `name`, `generator`, `options`, `createdAt`; експорт/імпорт — JSON-файл, імпорт пропускає некоректні записи.
- 404-сторінка зроблена самодостатньою (inline CSS, без зовнішніх файлів), щоб коректно відкриватися за будь-яким шляхом на Render; на `file://` посилання «На головну» веде на `index.html`.
- Мобільний перегляд листа A4 масштабується через CSS `zoom` (0.72 / 0.55 / 0.42 на 900/640/460 px), у друці `zoom` скидається до 1.
- `render.yaml` у корені: static site, `staticPublishPath: ./site`, кеш `fonts/*` на рік.
- Деплой: https://task-generators.onrender.com (Render Static Site, авто-деплой з гілки `main`).
